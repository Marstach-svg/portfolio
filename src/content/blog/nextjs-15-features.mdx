## Next.js 15 の主な変更点

Next.js 15 では多くの改善が行われました。この記事では特に重要な変更点をまとめます。

## App Router の改善

App Router がさらに安定し、パフォーマンスが向上しました。

### Server Components

Server Components がデフォルトとなり、クライアントサイドの JavaScript バンドルサイズが大幅に削減されます。

```tsx
// Server Component（デフォルト）
export default async function Page() {
  const data = await fetchData()
  return <div>{data.title}</div>
}
```

### Server Actions

Server Actions の型安全性が向上し、より直感的に使えるようになりました。

```tsx
async function createPost(formData: FormData) {
  "use server"
  const title = formData.get("title")
  // データベースに保存
}
```

## パフォーマンスの改善

- ビルド時間の短縮
- 開発サーバーの起動時間改善
- ホットリロードの高速化

## まとめ

Next.js 15 は開発体験とパフォーマンスの両面で大きな進歩を遂げています。
新しいプロジェクトを始める際はぜひ活用してみてください。
