## Framer Motion とは

Framer Motion は React 向けのアニメーションライブラリです。
宣言的な API で、複雑なアニメーションを簡単に実装できます。

## 基本的な使い方

### フェードインアニメーション

最もシンプルなアニメーションの例です。

```tsx
import { motion } from "framer-motion"

function FadeIn() {
  return (
    <motion.div
      initial={{ opacity: 0 }}
      animate={{ opacity: 1 }}
      transition={{ duration: 0.5 }}
    >
      Hello World
    </motion.div>
  )
}
```

### スクロール連動アニメーション

`whileInView` を使って、要素がビューポートに入った時にアニメーションを実行できます。

```tsx
<motion.div
  initial={{ opacity: 0, y: 50 }}
  whileInView={{ opacity: 1, y: 0 }}
  viewport={{ once: true }}
  transition={{ duration: 0.6 }}
>
  スクロールで表示されます
</motion.div>
```

### スタガーアニメーション

子要素を順番にアニメーションさせるテクニックです。

```tsx
const container = {
  hidden: {},
  show: {
    transition: { staggerChildren: 0.1 },
  },
}

const item = {
  hidden: { opacity: 0, y: 20 },
  show: { opacity: 1, y: 0 },
}

function StaggerList() {
  return (
    <motion.ul variants={container} initial="hidden" animate="show">
      {items.map((i) => (
        <motion.li key={i} variants={item}>
          {i}
        </motion.li>
      ))}
    </motion.ul>
  )
}
```

## パフォーマンスのコツ

1. **`will-change` は控えめに** - ブラウザに過剰なヒントを与えない
2. **`layout` プロパティを活用** - レイアウトアニメーションの自動化
3. **`useReducedMotion` をチェック** - アクセシビリティ対応

## まとめ

Framer Motion を使えば、少ないコードで印象的なアニメーションを実装できます。
ぜひプロジェクトに取り入れてみてください。
