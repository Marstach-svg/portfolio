## はじめに

ポートフォリオサイトにブログ機能を追加しました。
このブログでは、日々の開発で学んだことや、プロジェクトの振り返りを発信していきます。

## このブログの技術スタック

このブログは以下の技術で構築されています：

- **Next.js 15** - App Router を使用
- **MDX** - Markdown + JSX でコンテンツを管理
- **Tailwind CSS v4** - スタイリング
- **Shiki** - コードのシンタックスハイライト

## コード例

```typescript
const greeting = (name: string): string => {
  return `Hello, ${name}!`
}

console.log(greeting("World"))
```
